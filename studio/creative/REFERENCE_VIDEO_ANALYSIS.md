# Reference Video Analysis

PawanStudio accepts a user-supplied reference video as a creative research input. The system must analyze transcript, shot boundaries, pacing, framing, typography, caption behavior, transitions, audio structure, visual density and asset classes.

The output is a **differentiated production plan**, never a shot-for-shot clone. Preserve high-level principles (pacing, hook mechanics, information design, visual rhythm) while changing the subject, script, assets, compositions and creative treatment. Do not imitate a living creator's voice or likeness without authorization.

Minimum analysis record:
- duration, resolution, fps
- shot timestamps
- talking-head vs B-roll vs UI vs graphics
- caption timing/style
- camera/motion cues
- transition frequency
- audio/music/SFX cues
- visual pattern breaks
- narrative beats
- reusable abstract principles
- elements explicitly excluded from copying

Reference analysis should feed the Differentiation Engine and Shot Director before production begins.
