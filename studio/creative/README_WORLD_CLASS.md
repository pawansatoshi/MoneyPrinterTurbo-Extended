# PawanStudio World-Class Build

This is the target product contract, not a claim that every external provider is installed locally.

## User experience

A user should be able to say: `Make a 90-second educational video about <project>` and the Studio should infer a production pipeline, discover/verify official sources, build an evidence-backed brief, generate differentiated concepts, select a visual grammar, plan shots, acquire authentic/licensed assets, create narration/captions/audio, compose, review and revise, then export platform variants.

The website URL is optional. If project identity cannot be established with high confidence, ask for a seed URL instead of guessing.

## Quality bar

No slideshow-by-default. Every scene must have a narrative purpose and visual justification. Official UI/logo/data must come from verified sources. AI-generated media is for conceptual/supporting visuals unless explicitly supplied as the user's own source material. Unsupported factual claims block release.

## Creator identity

A creator may supply authorized photos/video/voice. Preserve identity and voice characteristics without deceptive claims. Voice cloning and likeness use require ownership/consent metadata.

## Reference-driven creation

A reference video may be analyzed for abstract production principles and used to create a differentiated plan. Never clone a creator's voice/likeness or reproduce a reference shot-for-shot.

## World-class acceptance test

A real project must pass all REQUIRED_STAGES in `production_contract.py`, including multimodal review and targeted revision. A successful FFmpeg exit alone is not sufficient.

## Provider philosophy

Local/open-source providers are first-class. Cloud providers are optional adapters. The Studio must expose provider choice, capability, cost and fallback information and keep credentials outside source control.
