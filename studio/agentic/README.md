# PawanStudio Agentic Production Core

This layer turns PawanStudio from a deterministic video planner into an agent-operated production system. The existing MoneyPrinterTurbo renderer remains the execution engine.

## Control loop
brief -> context -> research -> evidence -> thesis -> visual grammar -> storyboard -> asset plan -> provider routing -> voice/captions -> composition -> preflight -> render -> multi-review -> targeted revision -> post-review -> platform masters.

## Agent contract
The agent is the creative orchestrator. YAML pipeline manifests define stages/gates; Markdown skills define expert procedures; Python tools execute deterministic operations. Decisions, alternatives, confidence, provider choice, cost estimates and checkpoints are persisted.

## Mandatory gates
- authenticity gate before product scenes
- evidence gate before factual narration
- provenance gate before external assets
- consent gate before creator likeness/voice
- delivery gate before rendering
- post-render visual/audio/subtitle review before release

## Provider routing
Providers are capabilities, not dependencies. The router ranks candidates by task fit, quality, controllability, reliability, cost, latency and continuity. Local/open providers are preferred when they meet the requested quality; cloud providers are optional accelerators.

## Human control
Modes: automatic, director-approval, expert. The user can approve research, story, storyboard, or individual scene revisions. Interrupted jobs resume from checkpoints.
